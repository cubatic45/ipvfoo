IPvFoo Enhanced privacy policy

IP capture and local CDN header/hostname detection do not create metadata requests.
IP ownership lookup is disabled by default. If enabled in Options, opening the popup
sends public connection IP addresses to ipwho.is or the user's configured HTTPS
metadata service. The service also receives the network address making the request.
No page URLs, hostnames, response header values or browser cookies are sent in these
queries. Private and special-use addresses are excluded, including mapped IPv6.

Ownership settings and bounded cached ASN/organization/country results are stored
locally. Upstream context-menu lookup settings use browser sync storage. Context-menu
lookups happen only at the user's request and open the configured provider's page.
The fork contains no analytics, telemetry, advertising or backend service.

Users can disable lookup and clear cached ownership results in Options. Disabling
lookup aborts pending requests. Firefox built-in optional browsing activity consent
is requested when available and honored if revoked. Third-party services have their
own privacy policies and availability limits.
