IP ownership and CDN

Ownership lookup is off by default. When enabled, opening a popup sends public connection IPs to the selected service. Private and special-use addresses are never queried. CDN header and host detection works locally even when lookup is off. ASN indicates network ownership; CDN labels are estimates.
